# COMP 3512 — Assignment 2: Product SPA

A single-page application for browsing products, viewing details, and managing a shopping cart.

## Tech
- Vanilla JavaScript (ES modules), HTML, CSS
- Data from the bundled JSON file (later: the dummyjson.com API with localStorage caching)

## Run locally
ES modules and JSON imports won't load over `file://`, so use a local server:
```
cd comp3512-a2
python3 -m http.server 8000
```
Then open http://localhost:8000
